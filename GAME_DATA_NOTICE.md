# Game data notice

This repository contains **no** Xbox disc content, extracted game files, executables, textures, models, audio, video,
maps, saves, or other game data, and **no code generated from the game** (the recompiled C is produced on your machine
from your own `default.xbe` and is git-ignored).

To build or run the project you must supply your own legally obtained copy of *Godzilla: Save the Earth* (Xbox).
The game files are only ever read, never modified or uploaded. The project does not provide, host, or authorise
redistribution of copyrighted game data. Do not attach disc images, extracted files, generated code, dumps or
saves to issues, pull requests, releases or CI artifacts.

The function list in `ste/gen/functions.tsv` holds address ranges only; the XBE hash in `ste/gen/xbe.sha256` identifies
which build of the game the tree supports.
