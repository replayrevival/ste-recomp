## 1a. Instant typing (c425)
Still not instant. The only mechanism available without overriding game logic (REPORT_0.1.8 section 3) is the closed-loop press cycle; c425 shortens it again to 3 frames per press (hold 2, release 1, settle 0; every move is still checked against the screen; STE_TE_SPEED=2 = the c421 6 frames, STE_TE_SLOW=1 = the 0.1.7 12 frames). Test (F:\GodzillaSTE_work\clips_raw\kb425_turbo, STE_TE_TEST=GODZILLA): 32 presses over 124 frames (2.1 s; 0.1.7: 429 frames, c421: 217); the field shows GODZILLA (frame in F:\GodzillaSTE_work\dd_cmp\kt.png). That is 3.5x faster than 0.1.7 and typing a word takes about 2 s, but letters do not appear the moment a key is pressed. Instant typing needs either calling the script's append routine or writing the name buffer/cursor (both override game logic = STOP class, decision for Miko).

## 1b. Findings toward RAGE / UFO (no fix)
- Announcer cue table: SoundData\godzilla_voice_e.uber (5851 bytes, header 'UBER', sections PROJ / POOL / SDIR, 201 cue names at file offset 0x12AC.., among them index 142 `GAME OVER`, 163 `RAGE`, 164 `RED WINS`, 170 `TIME UP`, 171 `WINNER`) with the sample data in godzilla_voice_e.samp (998,212 bytes; the SDIR header carries that size). So "RAGE" is an ordinary entry of the English voice bank beside the working lines; no format difference is visible from the names. The script that plays announcer lines is ConventionalGame.bsf (contains TIME UP / WINNER). The rage power-up visuals (Powerup_rage_grab EDF, RAGE_POWERUP sfx cue) are in the per-monster .cmf and fx.bdl.
