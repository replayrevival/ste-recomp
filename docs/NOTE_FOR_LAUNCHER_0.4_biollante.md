# Note for the launcher session: Biollante recipe mod (0.4, in progress)

What: a new recipe mod `ste.biollante` (built like Solo Destruction: manifest api 2, edit lists + hashes, no game data). Build on the player's PC: `python -I tools\mods\iso_to_mod.py prepare <mod folder> <game folder|.iso>`; the four targets are `ShellData\ControlRoom.bdl` (new format `builtin:bio_ui`), `ShellData\monsterselect.bsf`, `ActionData\ConventionalGame.bsf` (`bsf-edit`) and `ShellData\attributes.xfg` (new format `text-edit`). Prepare needs `pw_bundle.py`, `bio_ui.py`, `texlib.py`, `bsf_edit.py`, `step_diff.py` next to `iso_to_mod.py` (all stdlib, no third-party tool). Takes under 2 s.
Player text: with the mod on, the select screen has a third row below the two retail rows with Biollante; she is playable as P1/P2/COM in Versus and Melee. The grid is a little smaller (scaled to 84 %) so three rows fit.
Needs the c435 runtime (front-end detection fix); with c434 the HUD is stretched and the menus lose the 4:3 pillarbox when this mod is on. Do not ship the mod enabled by default.
Mod author tool: `tools\mods\build_biollante.py <game> <out mod folder>`. Format reference: docs\formats\roster_slots.md, docs\formats\mod_build_recipe.md.

## Text for MODDING.md: "Add a monster to the roster"
A roster recipe adds a character to the select screen without shipping any game file. The select grid has the two retail rows and one extra row; every extra monster is one row in the slot table `SLOTS` of `tools\mods\bio_ui.py`: `{'name': 'biollante', 'row': 2, 'art': 'biollante_en', 'crop': (28, 34, 92)}` (`name` = the monster's script name, `art` = the portrait picture inside ControlRoom.bdl the four grid icons are generated from, `crop` = where the head is). Up to 12 per extra row, the row is centred automatically, the cursor handles a partly filled row, and nothing changes when the mod is off. You still need the monster's own data in the game files (model, animations, HUD bundle, sounds, `attributes.xfg` state, a `Setup<Name>AI` in ConventionalGame.bsf): Biollante's are on the retail disc, other monsters need their data added by another mod. Build with `python -I tools\mods\build_biollante.py <game> <out folder>` (copy and edit it for your monster), install, Prepare. Several recipe mods can be on at once; if two change the same script text, Prepare prints a CONFLICT line naming both. Reference: docs\formats\roster_slots.md. Credits: the idea of a third select page was done by ANILORAK on PS2 (research only; this is our own implementation).
## Known limits (roster_slots)
Preselect of a monster in an extra row when the screen reopens does not work (editing that script loop breaks the screen); the grid is 78 % of retail size.
