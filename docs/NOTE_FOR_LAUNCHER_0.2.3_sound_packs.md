# Note for the launcher session: sound packs (audio mods), 0.2.3 (candidate c432, NOT promoted yet)
Reference: docs\formats\soundpack.md (format, rules), docs\FEATURE_SOUND_PACKS.md (inventory, design).
1. **Mod type**: manifest `"profile": "sounds"` (Mods tab label "Sound pack"). Loaded from STE_MODS_DIR with order.json enabled/order like every mod; last_report.txt: `sound pack <id>: ACTIVE, K file(s)` plus lines for refused files and rebuilt banks/streams. Capability: `sound_mod_packs` (added to capabilities.json at promotion).
2. **Export**: `python -I tools\mods\sound_pack.py export <game folder|.iso> <out> [--match WORDS] [--category effects|voices|music|monsters] [--list]` -> `<bank>_<slot>_<cue>.wav` (effects/voices) and `<track>.wav` (music, monster jingles) + export_report.csv. Needs only Python 3.9+ (no Pillow). Example: `export "<game>" out --match RAGE` gives the announcer RAGE line and the RAGE effects.
3. **Build the pack**: `python -I tools\mods\sound_pack.py import <folder of edited WAVs> <game folder|.iso> <pack folder> --id my-sounds --name "My sounds" --credits "..."` -> manifest + `sounds\` + report.csv (matched / unmatched / format-refused / refused / duplicate, notes for length/mono/loop). Prints the next step and the copyright line.
4. **Replacement WAV**: PCM 16-bit, mono or stereo, any rate, up to 60 s; anything else is refused with a plain message (the original sound stays). Different length is fine. Bank sounds are mono (stereo is mixed down); music tracks are stereo 48 kHz (mono is duplicated). Loops: WAV `smpl` loop chunk (Audacity) = the whole bank sound loops; no loop chunk = plays once. Music has no loop marker (the game restarts tracks).
5. **Sample pack**: `python -I tools\mods\make_sample_soundpack.py <wav folder>` generates three synthetic tone WAVs (menu rollover beep, announcer RAGE cue as a three-note chime, a 14 s arpeggio for the first fight music); then `import` them. A ready folder for your Mods-tab test: F:\GodzillaSTE_work\e2e_snd\mods\sample-sounds (manifest + sounds\ + report.csv).
6. **Copyright line**: yes, the import tool prints it ("Share only audio you made or have the rights to; packs with copyrighted music or game voice clips are for personal use only").
7. **Behaviour**: nothing happens without an enabled sound pack (byte-identical to 0.2.2). With one, the first start builds the replaced banks into <STE_MODS_DIR>\_soundcache (a few seconds), later starts reuse them.
