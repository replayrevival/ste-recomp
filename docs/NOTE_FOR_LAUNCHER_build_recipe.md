# NOTE FOR THE LAUNCHER SESSION: build recipes (answers to your five questions)
Reference: docs\formats\mod_build_recipe.md. Applies to Solo Destruction now and Biollante in 0.4.

1. **How a recipe is declared.** No new manifest field: a normal api-2 manifest whose `patches` entries have `"format": "bsf-edit"` and `"patch": "edits\\<name>.json"` (list of old/new script snippets) plus `base_sha256` / `result_sha256`. The mod folder holds only manifest + `edits\` (about 85 KB, no game bytes), so it MAY be published/shared. Before the build the Mods tab sees a normal mod whose entries have no `_built\<target>`: show "needs build" (any entry with `format: "bsf-edit"` or a patch file and a missing `_built` file). After Prepare, `_built\` exists and the game uses it only if its hash equals `result_sha256`.
2. **Python.** The tools are plain standard-library Python 3.9+ (`tools\mods\iso_to_mod.py`, `bsf_edit.py`, `..\step-diff\step_diff.py`). The launcher cannot assume Python: either run them with an embedded Python you ship (about 10 MB, only stdlib needed) or freeze `iso_to_mod.py` with PyInstaller into one exe (it imports bsf_edit and step_diff); I have not frozen it, say if you want me to. No other tool is needed.
3. **Command lines.** `python -I iso_to_mod.py prepare <mod folder> <game folder or .iso>`. Exit 0 = all files built, 2 = at least one failed, 1 = bad usage. One line per file on stdout: `<target>: built`, `<target>: BASE MISMATCH (your file differs from the one the mod was made for)`, `<target>: script does not match what this tool expects (N matches ...). Is this the original Xbox game?`, `<target>: not in your game, skipped`, `<target>: RESULT MISMATCH`. Time: under 1 s for Solo Destruction (4 scripts); zip-of entries a few seconds. Use a spinner. Making the recipe mod (author side, not the player): `python -I tools\mods\build_solo_destruction.py <game> <out folder>`. For the player the shipped recipe folder is all that is needed.
4. **Who supplies gste_script_tool_v3.py.** Nobody: GZBuildr is no longer used. Policy (Miko 2026-11-20): third-party tools are never bundled or required at install time. Our own `bsf_edit.py` (GPL-2.0-or-later) replaces it.
5. **Photo mode.** Not built yet (0.3.1); keys, ini settings and capability name will come in its own note. Capabilities added now in artifacts\capabilities.json: `recipe_mods`, `solo_destruction_mod`.
Wording: nothing in these docs or the recipe refers to any community mod.
